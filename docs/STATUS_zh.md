## 1. 当前结论

项目已经具备完整的 M20 轮足机器人 + AgileX Piper 机械臂部署栈：

- MuJoCo sim2sim、策略部署、状态机、机械臂 IK、键盘/VR 遥操、真机臂桥接均已接入。
- 策略接口为 **83 维观测、10×70 history、16 维动作**。
- 默认策略是平地模型 `policy/m20_piper_flat_20260930`；多地形模型可用
  `M20_POLICY_DIR` 切换。
- 仿真主链路、机械臂链路和 VR 页面均已有可重复测试或真机实测记录。

**当前不能视为已具备长期无人值守上线条件。** 主要阻塞是：

1. SDK 站立保持仍存在热边界，前腿侧摆/膝关节可能接近或达到 100 ℃。
2. 厂商站立姿态与训练默认 RL 姿态不一致，进 RL 仍有入口瞬态风险。
3. 安全层中的低电量、命令心跳和部分反馈超时保护尚未完整接线。
4. 真机标定、时延、急停、机械臂驱动限速等关键链路仍需逐项验收。

## 3. 已完成能力

### 3.1 仿真与策略

- 修正旧 checkpoint、关节顺序、关节反馈坐标系、初始位姿和控制帧语义。
- MJCF 的 armature、执行器限幅、默认姿态和末端 FK 已与训练配置逐项核对。
- 支持平地、多地形和历史策略目录；`policy_layout.json` 驱动加载并做 ONNX 形状断言。
- 提供 L0 编译、L1 策略接口、L2 话题回环、L3 端到端、L3' MJCF 参数对照。
- 提供遥测 CSV、命令组合扫描、扰动注入、执行器延迟和实时因子检查工具。

### 3.2 机械臂与 VR

- 机械臂 IK 使用 DLS，可达目标稳态误差约 0.2 mm。
- 机械臂增益 300/8、夹爪 286/5，与训练配置一致。
- 修复 VR 手腕奇异位形导致的机械臂甩动；加入柱坐标映射、IK 收敛检查和 3 rad/s 限速。
- VR 复位语义统一为机身、机械臂和速度回默认，并交还控制权。
- 头显页面已离线化，A-Frame、PyYAML 和 websockets 的离线准备与自检流程已固化。

### 3.3 真机工具

- 提供真机预检、增量同步、DDS 排障和离线 Python 依赖方案。
- 提供假臂节点、真实机械臂适配器、VR/机械臂链路发布者检查。
- 提供 16 关节力矩与双温度录制、保持/卸力段识别和离线频谱分析。

### 3.4 统一键盘控制终端

- `scripts/keyboard_teleop_supervisor.py` 用一个 stdin 同时托管策略、IK 和臂键盘；
  腿/状态机键只发给 `rl_deploy`，小键盘只发给 `arm_teleop_node.py`，`G/L` 双发。
- 提供 `sim`、`real`、`arm`、`legs` 四种组合；任一子节点异常退出会停止整组，
  避免残留第二发布者。
- `run_sim2sim.sh` 的 `arm`/`mixed` 配置不再重复启动 IK；真实部署时 Jetson 驱动
  仍占一个终端，M20 上位机的 adapter/IK/臂键盘/策略收敛为一个控制终端。

历史验收不能再直接等同于“当前默认配置已验收”：

- `tests/sim2sim_smoke.py` 默认把站立/idle 固定为训练姿态档，而产品默认已改成厂商档。
- `tests/run_all.sh` 对 `arm` 档仍按单次 0 失败判定，与已知入口瞬态不一致。
- 当前默认“厂商站立 → 训练姿态 RL”的完整路径需要在修改测试口径后重跑。
- 策略入口后的偶发发散仍按 DEF-018 记录；站立状态机本身保持修改前实现。

## 6. 推荐工作顺序

1. 降站立刚度并做真机站姿扫描，先获得安全的站立包线。
2. 统一训练/部署初始姿态，重新测试厂商站立到 RL 的切换。
3. 补安全层和限位 bug，再做真机标定、时延、急停验收。
4. 修测试口径和残留进程检查，最后清理代码与文档债务。
